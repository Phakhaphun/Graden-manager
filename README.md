# Garden Manager of Purichaya garden

เว็บแอปสำหรับบันทึกและสรุปข้อมูลผลผลิตทางการเกษตร สร้างด้วย Python, Streamlit, SQLite, Pandas และ Plotly

## ความสามารถในเวอร์ชันเริ่มต้น
- บันทึกข้อมูลผลผลิต วันที่ ปริมาณ หน่วย ราคาขาย และต้นทุน
- คำนวณรายรับเบื้องต้นจากปริมาณ × ราคาต่อหน่วย
- ดูประวัติและค้นหารายการผลผลิต
- ลบรายการที่บันทึกไว้
- แสดงตัวเลขสรุปและกราฟรายรับแยกตามชนิดพืช

## วิธีติดตั้งและเปิดเว็บ

ต้องติดตั้ง Python 3.11 ขึ้นไปก่อน จากนั้นเปิด Terminal ในโฟลเดอร์โปรเจกต์

```bash
python -m venv .venv
```

Windows:
```bash
.venv\\Scripts\\activate
```

ติดตั้งไลบรารี:
```bash
pip install -r requirements.txt
```

เปิดเว็บ:
```bash
streamlit run app.py
```

เว็บจะเปิดในเบราว์เซอร์ โดยทั่วไปใช้ที่อยู่ `http://localhost:8501`

## ฐานข้อมูล
ข้อมูลจะถูกบันทึกไว้ที่ `data/garden.db` และสร้างตารางให้อัตโนมัติเมื่อเปิดแอปครั้งแรก

## ข้อควรตรวจสอบก่อนใช้จริง
- กำหนดหน่วยและวิธีบันทึกต้นทุนให้ตรงกับการทำงานของสวน
- ตรวจสอบว่าต้นทุนเป็นต้นทุนต่อรายการ ต่อรอบเก็บเกี่ยว หรือรูปแบบอื่น
- สำรองไฟล์ `data/garden.db` เป็นประจำ
- ก่อนนำไปใช้จริง ควรทดสอบการกรอกข้อมูลผิดพลาดและการคำนวณกับข้อมูลที่ตรวจสอบแล้ว
